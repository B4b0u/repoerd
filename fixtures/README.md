# Fixtures

Synthetic repositories served by the fake GitHub mode (`GITHUB_MODE=fake`, the demo mode) and used by tests.

- `repos/<owner>/<repo>/repo.json` declares the default branch and maps branch names to snapshot folders.
- `forkPoints` (optional) maps a branch folder to the folder of its fork point: `getMergeBase` answers that snapshot's commit for this branch, whichever side it is on. Fork-point folders are snapshots served like the branches but never listed as branches. Without a declaration, the merge base is the base commit.
- `formerNames` (optional) lists earlier `owner/name` of the repository: they lead to it, like a renamed repository on GitHub.
- Each snapshot folder is a complete copy of the repository at that branch.
- `acme/platform-monorepo` is generated by `pnpm exec tsx scripts/generate-platform-fixture.ts` — do not edit it by hand.

Showcases (the demo and the README screenshots):

- `acme/storefront` — Prisma 7 with `prisma.config.ts`, models in `prisma/models/`, an `inventory` Postgres schema, composite keys and a composite foreign key. Branch `feature/subscriptions` forks from `main-at-fork`; `main` moved on since.
- `acme/helpdesk` — Drizzle with `casing: 'snake_case'`, schema files spread over a barrel and a `@/` path alias, spread columns, extra config in array form (`unique().on()`, composite `foreignKey()`, `check()`), `pgEnum` and an `audit` Postgres schema. Branch `feature/sla-escalations` forks from `main-at-fork`; `main` moved on since.

Never copy code from real (company) projects here: this repository is public.
